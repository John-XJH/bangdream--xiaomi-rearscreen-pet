# BanG Dream 背屏桌宠源码候选 — ANON 66 / 助手0.14

## 项目结构与功能

phone-test/web 包含单/双角色渲染、点击动作与语音、独立大小位置、换装、背景渐变和图片模糊、自定义语音备注、15/30/60帧选择、默认关闭的智能省电、原生调暗冻结与唤醒、资源释放、诊断及新旧宿主加载桥接。compatibility/src 是Android助手、手势识别和本地诊断源码。tools 包含依赖获取、构建、安装及兼容加载工具。

## 复刻与构建

游戏素材及Live2D Core没有打包。四个素材目录索引为空，直接打开网页不能显示人物。必须自行准备有权使用的catalog、模型、动作、音频、背景及对应vendor运行库，结构见docs/资源结构.md。工具不会自动下载游戏素材。

在自己的Android SDK和JDK环境中运行 tools/fetch_gesture_dependencies.py，再按工具 --help 参数运行 tools/build_helper.py；这是显式联网获取官方手势依赖，本包没有携带依赖二进制、模型或签名密钥。助手示例使用原创占位图标，不能凭不同签名直接覆盖原助手。

使用 tools/build_wallpaper.py --web 指定有使用权的资源目录，--output 指定新的输出文件。工具覆盖候选程序代码并生成旧宿主bootstrap，保留经验证的统一MAML入口，不修改输入目录。

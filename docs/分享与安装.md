# 分享与安装 — ANON 66 本地候选

## 两种发布范围

公开源码包可用于代码评审、构建和扩展；公开安装工具包只含文档与检查/备份/推送脚本。它们不包含角色，也不包含系统妙享背屏APK。完整本机验收包含当前游戏素材与运行库，供本机验收留档；没有取得素材与运行库适用的分发权限前，不将其上传为GitHub Release或网盘公开下载。

他人要显示角色，必须准备有使用权且与当前程序结构兼容的 rearscreen。安装助手APK不会自动安装角色、不会自动获得系统背屏宿主能力。

## 安装执行链

1. 手机进入 设置 → 妙享背屏 → AI壁纸，先下载并应用自己的“唯美动漫”入口。入口缺失或版本不同，先检查，不保证可接入。
2. Windows准备Python3和Google Platform Tools，连接一台手机，开启USB调试并确认电脑授权。
3. 运行只读检查：`python compatibility/check_phone.py --adb-path "C:\platform-tools\adb.exe" --package "C:\pet\rearscreen"`。
4. 核对检查列出的主题目录。用“原壁纸应用前后文件变化”或核对对应入口确认主题ID；不能把开发机的ID套给其他手机。没有可确认的主题目录时停止推送。
5. 使用确认的ID安装：`python compatibility/check_phone.py --adb-path "C:\platform-tools\adb.exe" --package "C:\pet\rearscreen" --restore --theme 实际主题ID`。脚本先备份、再推送、再校验，不修改系统APK、不需要root。
6. 手机重新应用该AI壁纸；按验收清单验证。可用手机文件管理器安装自己编译或获准分发的助手APK，核对来源与签名。

日常使用可拔USB、关闭USB调试。以后检查/更新/恢复时再开启；关闭调试不会删除桌宠资源。助手手势权限是相机权限，与USB调试不同。

## 其他机型

17 Pro Max当前基线：2509FPN0BC、OS4.0.0.44.XPBCNXM、宿主RELEASE-1.0.2608211912、API37、WebView152.0.7977.88。17 Pro（904×572）、18 Pro（912×596）、18 Pro Max（976×596）是布局目标，不是实机认证；18系列尺寸来自已有用户预设，硬件参数和接入能力仍需验证。机型选项不会改变物理屏幕分辨率。

先收集机型、完整OS/宿主/WebView版本、实际副屏尺寸、壁纸入口，再安装。未测试机型不自动运行宿主重启命令。重启恢复、OTA升级、触摸与摄像头策略必须按对应版本实测。

## 恢复和卸载

黑屏或“桌宠加载中”长时间不变：在妙享背屏应用详情选择“结束运行”，再从原入口应用；仍失败收集该宿主日志。电脑 `--restart-host` 当前仅支持已验证的17 Pro Max，不清除应用数据。此路径是现有恢复方案，不代表OTA和开机恢复问题已彻底解决。

恢复原资源时，用脚本保存的手机资源备份中的 rearscreen，按同一已确认主题ID推送并校验，再应用；或改用系统普通壁纸。卸载助手仅移除助手功能，不自动删除已推送的资源。不要分发或公开整份手机备份、ADB密钥、签名密钥或完整日志。

## 手势与省电

从桌宠设置开启识别，首次授予相机权限后启动；比耶/单手比心，2.5秒最小间隔，语音结束后额外1秒。保持同一姿势只触发一次。闲置30秒、打开设置、熄屏、温控升高时释放；单次最多5分钟，会话停止后需重新开启。尚未实现“拿起手机无入口自动启动”。

角色15/30/60帧可选；温度、电量和系统省电状态不覆盖用户选择的15/30/60帧；温控只影响降渲染分辨率及暂停音波/手势的策略。40℃为本应用减负触发值，不是手机过热判定标准。设置页宿主请求1帧，网页停止操作后暂停更新，取消实时背景模糊。
